NEXA — simple username/password version

1. Extract this ZIP.
2. Put index.html in your GitHub repository.
3. Enable GitHub Pages.
4. This version has NO email system.

IMPORTANT:
This version stores demo accounts in the browser's localStorage. That means it is NOT a real shared online account database yet.
If you want accounts to work across different devices/browsers, Nexa needs a server/database backend. GitHub Pages cannot securely store passwords by itself.

The homepage, profile, account management, friend search, requests, and filters are included.
