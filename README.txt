NEXA V2 — clean single-file version

No Supabase. No email. No external account backend.

New:
- Working Explore page
- Larger Account Settings page
- Account, Profile, Appearance, Privacy, Security and Notifications sections
- Change username/display name/password
- Upload an image OR animated GIF as profile picture
- Use an image/GIF URL as profile picture
- Friend search and requests
- Home + Explore navigation

The site stores its demo data in browser localStorage. GitHub Pages cannot provide a shared secure account database by itself, so different browsers/devices will not share accounts in this version.
